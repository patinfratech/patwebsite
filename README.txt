PAT Infratech website
=====================
Upload everything inside this zip to the web root (public_html) of patinfratech.com. index.html is the home page.

Files
  index.html, about.html, services.html, technology.html, contact.html   the pages
  css/style.css     all styling; brand colours and fonts are the variables at the top
  js/main.js        mobile menu and the enquiry form
  assets/favicon.svg  browser tab icon (replace with the final logo)
  sitemap.xml, robots.txt  for search engines

Logo: the mark in the header of each page is a placeholder <svg class="logo-mark">. Replace it with the final logo.
Enquiry form: it opens the visitor's email app addressed to patinfratechkas@gmail.com. No server is needed.
